# NetworkBuster

NetworkBuster is a React and Vite frontend starter for a network operations
workspace. The initial screen provides a responsive landing page and feature
areas for network activity, security insights, and connected devices.

## Development

The application source is in `frontend/`.

```bash
cd frontend
npm install
npm run dev
```

Create a production build with:

```bash
cd frontend
npm run build
```

The current UI is a scaffold; connect these workspace areas to application
data and services as they are implemented.
